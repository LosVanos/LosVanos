## 👨‍💻 Sobre mim

Sou de Portugal e gosto de transformar ideias em projetos funcionais. O meu trabalho passa pelo **desenvolvimento de software**, criação de **interfaces web e desktop** e construção de **sistemas personalizados para FiveM**.

Preocupo-me especialmente com a experiência de utilização, a organização das funcionalidades e os detalhes que tornam uma ferramenta agradável de usar no dia a dia.

## 🚀 Projetos em destaque

### 🧩 C3D PRO

**Software de gestão de impressão 3D para Windows**, desenvolvido para makers e pequenos negócios.

Reúne ferramentas para calcular custos, criar orçamentos, gerir clientes, materiais, stock, impressoras e produção — tudo num único espaço de trabalho. O desenvolvimento continua focado em desempenho, estabilidade e experiência de utilização.

[🌐 Website](https://losvanos3d.pt) · [📦 Repositório de releases](https://github.com/LosVanos/C3D-PRO-Releases)

### 🎮 Última Paragem RP · Scripts LV

Desenvolvimento de recursos personalizados para **FiveM**, com lógica em **Lua** e interfaces **NUI**.

Trabalho em sistemas de HUD, crafting, processamento, economia e outras mecânicas para tornar a experiência de roleplay mais completa, consistente e intuitiva.

*Projeto em desenvolvimento; parte do código não está disponível publicamente.*

### 🖥️ GameDock

Projeto de aplicação desktop focado na organização de ferramentas e na experiência de utilização para gaming, com uma interface personalizável e funcionalidades de monitorização de hardware em desenvolvimento.

*Projeto em desenvolvimento.*
